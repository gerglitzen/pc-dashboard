# User guide

The dashboard has two pages. Swipe left/right, or tap **System** / **Tasks** in the header.

| Page | What it is for |
|---|---|
| [System](SYSTEM.md) | live status of the PC: CPU, temperatures, memory, network, GPU, disk, battery |
| [Tasks](TASKS.md) | your task board: time tracking, Clockify time entries, Notion tickets |

Common to both pages:

- The **dot** next to the host name is green while the page is connected to the PC (System: the stats stream; Tasks: the last save/load).
- The **theme** button (top right) switches between dark and light; the choice is remembered in that browser.
- Setup (Clockify / Notion keys, running the server) is in the [README](../../README.md).
